# Contributing to Clip Desk

Use [GitHub Issues](https://github.com/DroHadTo/cliprdesk/issues) for reproducible bugs and feature requests. Include your Clip Desk release, Windows and Python versions, and the steps and result you observed. Report vulnerabilities through the private channel in [SECURITY.md](SECURITY.md).

## Submit a change

1. Fork the project and work on a branch. Follow the [development instructions](README.md#development).
2. Use synthetic media and fixture accounts. Keep provider keys, footage, local databases, watchlists, and logs out of commits and issue attachments.
3. Run the worker and website test suites. For interface changes, include desktop and narrow-screen screenshots. For a release change, regenerate and verify the archives.
4. Open a pull request and describe the behavior, how it was verified, and any setup or migration impact.

Only submit code and assets you have the right to distribute. Contributions to the original Clip Desk code are covered by the [MIT License](LICENSE). Disclose any separate terms for third-party assets or dependencies.
